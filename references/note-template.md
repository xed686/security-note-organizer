# 笔记输出模板

成稿时按本模板搭骨架。方括号【】里是需要你填的内容。🔴 核心知识点用完整的 7 个模块;🟡 辅助知识点保留模块 1、2、3、5,案例可简写;⚪ 了解级别只写一小段。

---

## 整体骨架

````markdown

> [!info] 🧭 知识导航
> 所属:【用户的知识库首页,如果用户提过】 ｜ 上一篇:【真实存在的笔记名,否则写"待补"】 ｜ 下一篇:【同左】
> 🔗 相关:【仅列出用户提过的、真实存在的笔记】

> 一句话总结:【本篇最核心的一个结论,小白读完这句就知道学了什么】
> 来源:【课程 / 文章 / 实验名称;由 Claude 补充的部分会用"🔎 补充"标注】
> 适用前提:仅限授权环境、靶场、CTF。
````

## 补充标注块的写法

```markdown
> [!note] 🔎 补充(非原笔记内容)
> 【这里是你补充的原理 / 案例 / 背景。写明这段不是来自原资料】
```

## 其他格式

默认 `.md`。如果用户指定 Word / PDF 等格式,保留同一套骨架,仅改变呈现方式,并先读取对应格式的 skill。
